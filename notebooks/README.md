# Notebooks

`reproductions.ipynb` is one Google Colab notebook holding every
reproduced paper. It is generated by

```bash
python -m tools.notebooks          # write notebooks/reproductions.ipynb
python -m tools.notebooks --check  # fail if the notebook is stale (CI)
```

The notebook opens with the recorded results of all papers and one setup
cell that clones and installs this repository on Colab. Each paper then
has its own section with its reproduction report, its recorded results,
and cells that rerun its smoke and full configurations. The recorded
results are visible without running anything.

The notebook is built from `papers/<paper_id>/README.md` and `results/`,
so edit those files and regenerate rather than editing the notebook.

To use it in Colab, open
[the notebook from GitHub](https://colab.research.google.com/github/navidsharifi/optora-reproductions/blob/main/notebooks/reproductions.ipynb)
and save a copy to Drive, or download the file and upload it with
File, Upload notebook.
