# Notebooks

One Google Colab notebook per reproduced paper, generated by

```bash
python -m tools.notebooks          # write notebooks/<paper_id>.ipynb
python -m tools.notebooks --check  # fail if a notebook is stale (CI)
```

Each notebook shows the paper's reproduction report and its recorded
results without being run, and its code cells clone this repository on
Colab to rerun the smoke and full configurations. The notebooks are built
from `papers/<paper_id>/README.md` and `results/`, so edit those files and
regenerate rather than editing a notebook.

To use one in Colab, either open
`https://colab.research.google.com/github/navidsharifi/optora-reproductions/blob/main/notebooks/<paper_id>.ipynb`
and save a copy to Drive, or download the file and upload it with
File, Upload notebook.
